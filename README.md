# Finance

Application web auto-hébergée et open source de suivi de patrimoine : PEE, PEA, compte-titres,
assurance-vie, Livret A, avec actions et ETF, fonds et SCPI. Les données restent chez l'utilisateur,
chiffrées au repos.

Le projet est en cours de conception : la constitution, la spécification et le plan du premier lot
sont dans [`.specify/memory/constitution.md`](.specify/memory/constitution.md) et
[`specs/001-wealth-dashboard-foundation/`](specs/001-wealth-dashboard-foundation/). Le contexte
produit est dans [`docs/design-brief.md`](docs/design-brief.md). Les instructions d'installation
arriveront avec le code.

Les valeurs et analyses affichées sont indicatives et ne constituent pas un conseil en
investissement.
